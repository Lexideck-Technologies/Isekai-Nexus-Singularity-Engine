# World access agreement

Read [the installed world library](world-library.md) for the 45 destinations and their exact full-file paths. Use the player's selected campaign revision when already readable. Otherwise open the selected complete local world file, or use a complete uploaded or pasted document. Match its title to the destination and actually read its contents before start selection, character evaluation, arrival, or passage.

If the full document is unavailable or unreadable, ask once for that complete file or pasted text and preserve character facts, motivation, promises, selected start, destination, and pending decisions while waiting. A name or summary alone does not establish full-world access. An explicitly requested original world uses World Building and its complete world frame; confirm its selection before entering it.

Use the selected world's lore, current revision, custom openings, and native starting packages. Ask one targeted question for a material contradiction or missing fact. Player-approved additions remain campaign-specific. Record provenance as local-library, uploaded, pasted, completed-supplied, or generated-original, with actual document title, revision, and storage status.

Origin lore that matters uses the same readable-document rule. On return to a known destination reuse its established campaign version. Preserve accepted traveler identity and earned state across worlds. Continue from pending decisions rather than repeating completed intake.
