# World, magic, and dungeon references

Source: pinned v5.1 WORLD.TYPES, DUNGEON.TYPES, DUNGEONBYWORLD.MAP, and MAGIC.SYSTEMS. Use these as authoring affinities, not compulsory local danger. The complete selected world determines actual conditions. See [world access agreement](world-index.md), [character power bands](character-rules.md), [Resolution](resolution-rules.md), and [Progression](progression-rules.md).

## World types

| Rank | Type | Signature |
|---|---|---|
| F | Mundane Earth 2.0 | Barely noticeable magic; near modern Earth. |
| D | Standard medieval fantasy | Knights, kingdoms, common monsters; typical F/D power pool. |
| C | Game-like world | Visible stats, levels, skill trees; explicit System rules. |
| B | Dystopian wasteland | War or cataclysm, scarce resources, survival. |
| A | Magitech civilization | Integrated magic and technology with distinct sciences. |
| AA | World of gods and demons | Active deities, demon lords, divine politics. |
| AA | Weird wild west | Frontier magic and a gold-rush setting. |
| AAA | Multi-layered realm | Connected dimensions and planes; reverse crossings can occur. |
| S | Sentient planet | A living world that tests, nurtures, or threatens inhabitants. |
| SS | World of unfathomable horrors | Cosmic horror and incomprehensible beings. |
| SSS | Conceptual universe | Concepts manifest physically and fundamental laws differ. |

Both named AA types retain AA classification. World classification, site threat, and character power are distinct fields. A vast AAA world can have F-D starting opportunities.

## Magic systems

| System | Source | Activation and character | Typical affinity |
|---|---|---|---|
| System-assisted | World System | Think the spell name and pay MP; efficient, chantless. | Game-like, magitech |
| Elemental channeling | Personal will | Gesture or chant with focused will; expressive, slower. | Medieval, sentient planet |
| Divine granting | Gods or patrons | Prayer or invocation; scales with faith. | Gods and demons |
| Runic or array magic | Knowledge and glyphs | Draw circles or runes; slow, reliable, repeatable. | Magitech, ancient ruins |
| Blood magic or sacrifice | Life force | Blood or another established catalyst; HP cost, often forbidden. | Wasteland, horror |
| Conceptual weaving | Understanding reality's axioms | Act through understood core concepts; axiom rewriting belongs to SSS. | Conceptual universe |

Affinities allow exceptions. Use accepted character access, world casting conditions, and declared actions. Record costs before use. A system name does not confer an Authority, bypass consent, or authorize sacrificing another character. Lesser ranks can investigate concepts without acquiring SSS axiom rewriting.

## Dungeon types

| Rank | Type | Signature |
|---|---|---|
| F | Goblin cave | Straight tunnels, goblins, rats. |
| D | Ruined castle | Cursed halls, traps, undead. |
| C | Living labyrinth | Shifting layout, possibly living walls, instance portals. |
| B | Elemental temple | Elemental themes and resistant guardians. |
| A | The Abyss | Bottomless, layered ecosystems; each depth opens a biome. |
| AA | City of the ancients | Buried civilization, deity-domain extensions, AA guardians. |
| AAA | Floating planar castle | Multiple floors, each potentially a world, connected by rifts. |
| S | Sleeping god's dreamscape | Surreal thought-shaped reality and planetary antibodies. |
| SS | Infinite library | Written and unwritten books, non-Euclidean incursions bleeding into reality. |
| SSS | Core of creation | Multiversal reality substrate and metaphysical constructs. |

The floating castle uses an original generic name in place of the source's named-media comparison. Preserve its floor-world and rift structure. Always allow exceptions. Site structure does not impose a global floor seal, respawn schedule, or power reset. Establish such conditions in the actual site before using them.

## World-to-dungeon affinities

| World type | Typical site and features |
|---|---|
| Mundane Earth 2.0 | F anomalous zones: abandoned subways, covert corporate labs, dimensional bleed. |
| Standard medieval fantasy | D ruins, cursed forests, monster lairs. |
| Game-like world | C resettable instances, entry portals, floors, boss chambers. |
| Dystopian wasteland | B collapsed cities, scavenger fortresses, mutated hives. |
| Magitech civilization | A malfunctioning labs, crashed sky fortresses, abandoned magic factories. |
| Gods and demons | AA deity-domain extensions, holy sanctums, demonic territories. |
| Multi-layered realm | AAA planar rifts, gates, floating floor-world complexes. |
| Sentient planet | S biological dungeons and antibodies testing inhabitants. |
| Unfathomable horrors | SS non-Euclidean incursions, reality bleed, unclear entry boundaries. |
| Conceptual universe | SSS metaphysical constructs, lost-concept archives, reality substrata. |

The source gives no separate Weird Wild West dungeon row. Author a world-native site using these affinities and mark its actual rank; do not claim a missing canonical row exists. Use [Expeditions](../../isekai-expeditions/SKILL.md) for entry, maps, encounters, checkpoints, retreat, and reentry. A genuine world crossing also uses Travel and Arrival.
