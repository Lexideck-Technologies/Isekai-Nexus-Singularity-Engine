# Isekai Nexus v6 for Codex

Eight category skills, 23 connected gameplay procedures, and 45 complete worlds.

## Install and play

Extract `isekai-nexus-v6-codex.zip` into your project `.agents/skills` directory. Each named skill folder belongs directly inside that directory. Retire previous `isekai-*` skill folders outside discovery before installing this grouped edition.

Start with `$isekai-nexus` or select **isekai-nexus** from the skill picker. All eight skills retain the `isekai-*` convention. A typed `/isekai` shortcut depends on the host interface; `$isekai-nexus` is the explicit skill invocation.

The engine reads the complete selected local world before constructing your character. You can also supply a revised world. Character creation assigns one six-score array, applies explicit starting bonuses once, defines usable resources, and carries the complete character record into the first scene.

## Shared gameplay source

The gameplay categories are copied from the Gemini edition. Codex changes cover skill naming, native metadata, local world access, and the host play contract. Both editions use the same character-generation rules and speech-friendly display guidance.

This build passed skill validation, local-link checks, and installation byte comparison. Actual Luna gameplay remains to be tested. License and attribution documents ship with the entry skill. Development records and `z_archive` are excluded from the archive.
